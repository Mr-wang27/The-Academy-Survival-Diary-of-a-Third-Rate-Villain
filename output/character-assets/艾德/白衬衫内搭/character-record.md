# 艾德｜白衬衫内搭｜角色档案

## 参考来源

以人物资源/艾德中的原始漫画分镜为主：侧脸+身材.jpg、俯视+疲惫.jpg、俯视视角1.jpg、正脸+无语神情.jpg、战斗远景侧身整体.png、战斗正面1.png、战斗正面2.png。

## 锁定设计

- 17岁人类男性，修长而有运动感的少年体型；浅肤色。
- 浅金色短发，顶部蓬松分束，侧分刘海由左向右斜落并遮住部分额头；耳侧和后颈为短碎发。
- 蓝灰色眼睛，细长略上挑；面部偏窄，下颌清晰，日常中性、轻微疲惫的表情。
- 内搭为白色长袖翻领衬衫、红色长领带、深灰近黑修身长裤、黑色皮鞋；衬衫可见袖口，领带笔直垂落。
- 纯浅灰白背景、无文字无道具、漫画线稿与赛璐璐阴影。

## 设定边界

- 白衬衫是学院服内搭的独立版本；不出现红色学院外套。
- 背面不可见处依照前后发长和衣物结构做保守补全：短碎发后颈、衬衫后背和裤装结构保持简洁。
