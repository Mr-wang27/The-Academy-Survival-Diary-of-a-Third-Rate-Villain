# 帕尼亚皇女｜皇女服｜元素档案

- **类型**：人物服装与角色视觉元素
- **名称**：帕尼亚皇女（皇女服）
- **参考范围**：`人物资源/帕尼亚皇女/皇女服/帕尼亚皇女-皇女服-066-067-合并完整人物-v1.png`
- **整体定位**：浅蜜桃金长发的年轻皇女；白色、浅蓝灰与金色构成的轻礼服，华丽但保持柔和、清透的日式动漫质感。

## 角色辨识与穿戴关系

- **脸型与五官**：白皙肤色、偏椭圆的年轻脸型；金黄色瞳孔，深色上眼线；小幅闭唇微笑。
- **发型**：浅蜜桃金／浅金长发；额前为中分偏侧扫的长刘海，面颊两侧有长发束，主体为多层流动长发。
- **比例与姿态**：纤细身形，原图为漂浮感的三分之四正面站姿；姿态不是服装设计锚点。
- **服装层次**：深蓝金边立领 → 白色泡袖与紧身胸衣 → 浅蓝灰长袖 → 金色腰饰 → 白色外层大摆裙 → 浅蓝灰内衬；下身为左右异色长袜与白金尖头鞋。

## 一致性提示

1. 必须保留浅蜜桃金长发、金色瞳孔、深蓝金边高领、白色泡肩、浅蓝灰双层裙摆与金色卷叶腰饰这六项设计锚点。
2. 金色装饰应为细窄的卷叶／藤蔓式金属件，不替换成王冠、宝石胸针或大型徽章。
3. 左右异色长袜及交叉金线是下身的关键不对称设计；不要改为同色丝袜。
4. 原始素材未展示清晰背面、侧面、鞋后跟及袖口内侧结构；这些部位均为**待确认**，后续不得据此档案擅自扩展为确定设定。
5. `01`、`02` 为依据参考生成的透明背景独立资产；`03` 至 `07` 为原立绘的可核验局部裁切，保留原图背景与邻近轮廓，仅用于细节对照。
