# 漫画与小说双源动画制作

项目根目录的 [动画工作流](../../../动画工作流/README.md) 是唯一流程依据。本技能负责选择当前阶段、定位真实来源并执行；若有冲突，以工作流为准。按需读取 [分集执行模板](../../../动画工作流/分集执行模板.md)、[视觉风格圣经](../../../动画工作流/视觉风格圣经.md)、[提示词与质检规范](../../../动画工作流/提示词与质检规范.md)，不要一次载入所有文件。

1. 先看用户要求和既有 `章节剧集/<EP-ID>/制作包.md`，从上次完成的复核点继续。没有制作包才复制模板。只读本集相关漫画页、小说段和资产图；漫画话数与小说章数不得按编号硬配。
2. 按工作流三个复核点推进：故事依据 → 可制作的镜头方案 → 生成、剪辑、终审。一次请求可连续推进多个点；重大未决冲突只暂停受影响镜头。来源、推断和批准版可追溯，未核验内容标 `待核`。
3. 角色以 `output/character-assets` 中本集已核验版本为准；场景无批准版时仅补受影响场次的最小场景板。逐镜提供实际景别所需参考。详细视觉和提示词规则只从工作流对应文件取用。
4. 制作包承载结果和最短交接摘要，不另建同内容的八份阶段文档。长资料用路径与页段索引。每轮只保存本次变更、未决项、下一步和版本。
5. 并行 agent 按工作流的条件和上限启用。分配不重叠的来源页段、场次或资产范围；主 agent 统一裁定冲突、合并跨场状态和终审。预算紧或任务短时单 agent 执行。

剧情核验读取工作流 A 和制作包前半部分；剧本/分镜读取已核验单元及本场资产；逐镜生成读取本镜、风格圣经和提示词规范；跨集修订定位原始证据并更新受影响下游。完成标准以工作流三个复核点为准，不把未生成的提示词包说成已完成动画。
