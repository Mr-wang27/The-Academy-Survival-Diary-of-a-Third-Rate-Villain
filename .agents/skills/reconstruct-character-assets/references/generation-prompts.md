# ImageGen 提示词模板

实际提交图片并按顺序编号，说明档案 R 编号与图片序号的映射。选用与目标相关的清晰参考，不用一句“完全一致”替代具体约束。

## 全身视图

```text
任务：依据附带漫画参考制作【角色 / 服装】的【正面 / 角色自身左或右侧面 / 背面 / 三视图】资源。
参考分工：图片1（Rxx）约束【脸与头发】；图片2（Rxx）约束【服装结构】；图片3（Rxx）约束【腿与鞋】；图片4为已检查生成基准，仅约束【已核验特征】。
画风：【原作线条、上色和色彩的具体观察】；保持原年龄感与身体比例。
构图：【单视图或布局】，平视，低透视，自然站姿，完整显示头顶至鞋底，【背景】。
固定特征：【已确认细节，明确数量、形状、位置、角色自身左右】。
比例：【有证据的头身、肩腰、裙长、膝线与鞋口关系】。
允许变化：【必要的朝向、姿势、表情和背景】。
冲突解决：【权威来源和具体采用设计】。
补全设计：【C 编号、具体形状/材质/连接关系、所依据的 R 编号及氛围约束；仅在默认补全模式或用户授权范围内填写，无则删除】。
补全边界：只在上述缺失部位应用登记方案，保持所有已确认特征；未展示的内部结构保留自然遮挡。补全部分应与其他视角连续一致。
禁止：新增饰品纹样、改领口、交换饰品左右、镜像、改眼型刘海、拉长腿、改鞋型、裁掉头发鞋子、加入其他角色或漫画文字。
```

## 漫画证件照 / 正面头像

```text
任务：制作【角色 / 服装】原漫画画风的正面头肩像。
参考职责：【原始脸部、发型、领口参考和已检查基准】。
构图：平视正面、头部不倾斜，【表情】【背景】，完整发顶及必要肩部和领口。
保持：【脸部比例、眼型瞳色、眉睫、刘海分束、发际线、肤色和领口饰件】。
禁止：真人化、美颜换脸、改变年龄感、左右翻转、添加耳饰或臆造配件。
```

## 定向修正

```text
编辑目标：图片1【本次输出】。
修正依据：图片2（Rxx）的【具体部位】，或已登记补全方案【C 编号与版本】；明确是原始证据还是补全约束。
只修正：【当前错误】为【原图可见的正确结构 / 已登记补全设计】。
保持：【其他面部、发型、身体、服装、饰品、姿势、构图和画风锁定项】。
不得通过裁切、额外遮挡、镜像或移除饰品解决错误。
```

## 生成记录

在 `generation-log.md` 逐次记录：资产版本、实际工具、真实输入文件和 R 编号、采用的 C 编号及版本、完整提交提示词、返回文件、保存位置、检查结论和后续修改。不要将计划参数写成已执行参数。
