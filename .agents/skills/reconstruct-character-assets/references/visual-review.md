# 视觉验收清单

查看输出与原始参考，逐项记录符合、失败、无法判断或不适用。需要时查看局部原分辨率；不能以分辨率大或画面漂亮代替验收。

| 检查项 | 必查内容 |
| --- | --- |
| 人物身份 | 脸型、五官位置、眼型瞳色、眉睫、年龄感 |
| 头发 | 发际线、刘海分束、鬓发、发长发尾、轮廓和发色 |
| 服装 | 领口、肩部、前后衣片、腰线、裙摆、袖口、开衩、接缝和图案 |
| 饰品 | 件数、轮廓、颜色、连接关系、佩戴侧和大小位置 |
| 身体与腿 | 头身、肩腰臀、腿长、露肤范围、膝线、袜口；排除俯视缩短 |
| 鞋履 | 鞋口、鞋尖、鞋跟、可见鞋底、绑带和扣件 |
| 视角 | 正面正对、侧面无三分之四偏转、背面朝后、左右明确 |
| 跨图一致 | 身高尺度、头身比、衣长发长、腰膝脚底线和饰品位置 |
| 画风 | 原作线条与上色，无自动真人化和额外美化 |
| 头像 | 与全身相同面部设定，头肩构图、完整发顶与必要领口 |
| 输出 | 实际尺寸、可打开、构图和背景；要求透明时实际检查 alpha |
| 来源 | 原始证据与 C 补全编号分开、无混用服装、无将生成细节当作原作证据 |
| 补全结构 | 与领肩、侧缝、腰线、裙摆、发束或鞋型连续，符合登记方案，无未登记新增设计 |
| 补全氛围 | 配色、材质、装饰密度、年龄感、剪裁与原有气质一致，未按角色称谓刻板添加装饰 |
| 补全同步 | 各视角引用同一 C 方案版本；修改方案后全部受影响资产已复核 |
| 交付完整性 | 默认模式下完成全部请求视角；不得只因无原始背面就省略背面；证据限定模式注明缺口 |

在 `review.md` 逐个输出记录：

| 输出与版本 | 检查项 | 原始参考 R / 补全方案 C | 结果 | 具体差异 | 修正或补全说明 |
| --- | --- | --- | --- | --- | --- |

已确认的身份、服装或饰品被改动时标为“需修正”；补全设计与登记方案、结构或氛围不符时同样标为“需修正”；未能查看时标为“待检查”。两类验收均通过且包含补全时标为“已检查且含推定补全”，可作为完整资产交付，但不能标为全部经原作证实。不用总体相似度百分比掩盖具体失败。

完成必要修正和复核后停止额外变体生成。反复修改仍不符合时，将最接近版本明确作为未通过候选交付，说明需人工精修或补充哪个部位的参考。
