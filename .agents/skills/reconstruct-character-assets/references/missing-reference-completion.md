# 参考不足时的补全流程

在默认“忠实还原＋保守补全”模式下执行。目标是补齐用户请求的视角或局部，同时保持角色身份、已知设计、整体氛围和跨图结构一致。先核验，再设计，再生成；不要把判断缺失资料的工作留给绘图模型。

## 1. 建立缺失清单

逐个视角检查可见部位。区分已有证据、模糊但可交叉验证、原有自然遮挡、真正缺失、互相冲突。先检查现有图片的局部和其他角度，再决定需要补全；不把低清误读成不存在。

将必须在输出中显示的缺失部位登记为 C01 等编号。完全被原有头发或衣物遮住的内部结构可保留未知，不必凭空设计；不要额外加长头发或改变遮挡以逃避补全。人物自身左右与朝向分别记录，不能把“面朝画面左边”直接当作“角色左侧面”。

## 2. 提取角色氛围约束

从参考中的形状、配色、材质、装饰密度、剪裁、身体比例、年龄感、线条与阴影归纳具体约束。例如“浅冷色衣料、光滑无纹样、少量金属饰件、轮廓简洁”，而非只写“符合氛围”。将角色气质与当时的愤怒、惊讶、逆光等场景状态分开。

不要仅因名字含“皇女”便添加王冠、披风、纹章、宝石或宫廷刺绣；不要把典型职业服装替代参考中已有服装。身份称谓只能辅助理解，不能覆盖图像证据。

## 3. 制定最少必要补全

按以下顺序选择能够同时解释全部参考的最简单方案：

1. 延续已可见结构：衣片边缘、侧缝、裙长、领口高度、发束走向、鞋口和鞋底厚度。
2. 结合多视角建立连续关系：前后衣片在肩、腋下、腰和下摆衔接；同一饰件位置随视角变化，不能复制到另一侧。
3. 对仍缺失处采用同类衣物或人体的普通结构作为推定，匹配已有轮廓、材质和装饰密度。已观察到对称的部位才可延用对称关系，不自动镜像发型、臂环、徽章或其他不对称特征。

| 缺失内容 | 补全方式 | 不允许的变化 |
| --- | --- | --- |
| 背部衣片 | 延续已知侧缝、领肩关系、腰线和面料，采用简洁后片；自然遮挡处不展开内部结构 | 为了华丽增添露背、蝴蝶结、披风、纹章或醒目拉链 |
| 发型背面 | 依据侧面长度、发量、发束方向延续整体轮廓 | 擅自增加辫子、束发、发饰或改变发长 |
| 鞋后跟或鞋底 | 延续已见鞋型、跟高、鞋底厚度和绑带；局部不可辨时采用最简单一致结构 | 将平底鞋改为高跟鞋，新增厚底、装饰扣或品牌纹样 |
| 腿或部分身体 | 延续可见比例、年龄感、姿态和画风；避开夸张透视 | 无依据拉长腿、改变体型、露肤范围或性感程度 |
| 仅有头像而缺少服装 | 若还有明确文字设定，按设定补全并标注；若服装类型与轮廓都无依据，先完成头像并询问一个必要设计方向 | 将任意整套新服装声称为保守还原 |

如果缺失涉及整套造型或角色身份而非可延续的局部，且没有任何可约束的文字或图片依据，只询问真正决定结果的设计方向。普通背面、接缝、鞋跟等缺口无需逐项确认。

## 4. 先登记方案，再生成

在 `character-record.md` 记录每个 C 编号的：缺失部位、R 参考、采用方案、氛围依据、不可改变项、影响视角、推定范围和版本。默认选一个保守方案继续执行，不为每个小部位生成多套候选让用户选择。

若多个结构都可行，选择新增设计最少、与现有侧面衔接最好的方案；记录选择理由。将其作为本次项目补全设定固定使用，不将其升级为原作证据。

## 5. 逐视角生成与同步

先制作证据最充分的基准，再生成缺失视角。每次同时传入相关原始参考和已检查基准，在提示词中分别写出“原作锁定项”和“本次补全 C 编号及具体设计”。避免只写“合理想象背面”。

先检查补全视角能否在轮廓、接缝、饰品位置和比例上与现有视角衔接，再制作其余资产。若新视角暴露补全方案矛盾，修改 C 方案版本及受影响资产；不为迁就补全而修改已确认的原始设计。

## 6. 分别验收并完整交付

原图部分按原始证据验收；补全部分按登记方案、结构连续性、角色氛围、跨图一致性验收。发现未登记的新增设计，先删除或定向修正，不能事后全部认作合理补全。

在验收表注明“已检查且含推定补全”及 C 编号。完整交付全部已通过检查的请求资产，简述哪些部位使用补全；补全说明放在记录和回复里，不默认在图片上印字。

后续出现新原始参考时，优先用新证据替换相应 C 设定，保留版本历史，并检查所有引用它的视角和头像。
