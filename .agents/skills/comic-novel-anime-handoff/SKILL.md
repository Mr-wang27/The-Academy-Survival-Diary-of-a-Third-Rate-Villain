# 跨对话动画制作

使用项目根目录的 [跨对话动画分工工作流](../../../动画分工工作流/README.md)，按 [任务契约](../../../动画分工工作流/任务契约.md) 执行用户指定的 `EP-ID + T0–T6 + 范围`。本技能是独立入口；不要修改旧版 `动画工作流/README.md`、旧技能或旧版 `章节剧集/<EP-ID>/制作包.md`。

1. 先读 `章节剧集/<EP-ID>/分工制作包/00进度.md` 和本任务直接上游的相关部分。首次 T0 才从 [制作包模板](../../../动画分工工作流/制作包模板.md) 建立进度表。缺少 EP-ID 或任务编号时，先根据用户给定目标确定可执行的最小任务；无法确定集别时询问。
2. 只读取本轮页段、场次、镜头需要的原作和素材。旧目录的视觉风格圣经仅在 T2–T6 涉及视觉时按需读；提示词与质检规范仅在 T4 或相关质检时按需读。漫画与小说按事件对应，来源和批准状态必须可追踪。
3. 本轮只写任务契约指定的交付文件和 `00进度.md` 本任务行。范围过大时切成可独立保存的小批次，在进度中记录已完成与剩余范围。上游重大冲突只暂停受影响部分，其他已核验部分可继续。
4. 结束前按本任务完成判据核验，写最短交接摘要和下一对话可直接发送的交接句。断线后先核对磁盘成果再续做，不能把计划、未审核素材或未生成成片标为完成。
