# 动画分工自动调度

先读 [自动调度规则](../../../动画分工工作流/自动调度.md) 和 [分工工作流](../../../动画分工工作流/README.md)。本技能只负责调度；实际制作对话使用 `comic-novel-anime-handoff` 及 [任务契约](../../../动画分工工作流/任务契约.md)。用户要求制作完整一集并提供来源时启动自动分工；明确指定旧流程、单任务、教学或示例请求时按用户实际范围处理。

启动时确认 EP-ID、源路径、共享本地项目、真实工具能力及现有 `00调度.md`。从已有记录恢复，不能重复派发。使用 `list_projects` 确定项目；**每次派发或返工都用 `create_thread` 建立一个全新、有明确 T 编号和范围的 local 项目对话，绝不复用已用过的制作聊天**。旧聊天仅供 `wait_threads`／`read_thread` 查状态与历史，不向它发送后续制作任务。核对磁盘交付后才派发下一个；每次派发立即把新对话 ID 和范围写入 `00调度.md`。不要在调度对话里亲自执行 T0–T6。

为无人值守的运行创建本集 heartbeat，令每轮只检查状态、验证交付并派发下一批；未变化时保持安静，完成或停止时停用。断线后先查已保存记录、子对话和文件。重大冲突、素材批准、缺少实际视频/声音/剪辑能力及其他无法由证据决定的事项，应记录精确受影响范围并请求用户决定。只有真实成片通过 T6 后才宣布完成。
